Git Commands Cheat Sheet

1. Khởi tạo và Clone

Khởi tạo một repository mới:
git init
Clone một repository từ xa:
git clone [url]

2. Thêm và Commit

Thêm các thay đổi vào staging area (chuẩn bị commit):
git add .
Lưu các thay đổi với một thông điệp rõ ràng:
git commit -m "Thông điệp commit"

3. Nhánh (Branching)

Liệt kê tất cả các nhánh hiện có:
git branch
Tạo một nhánh mới:
git branch [branch-name]
Chuyển sang làm việc trên một nhánh khác:
git checkout [branch-name]

4. Đồng bộ hóa (Syncing)

Lấy dữ liệu mới nhất từ remote server về máy:
git pull origin [branch-name]
Đẩy các thay đổi của bạn lên remote server:
git push origin [branch-name]

5. Trạng thái và Lịch sử

Kiểm tra trạng thái của các file (đã sửa, chưa track...):
git status
Xem lịch sử các commit đã thực hiện:
git log
