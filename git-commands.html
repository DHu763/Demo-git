Các Câu Lệnh Git Phổ Biến

Khởi tạo & Sao chép

Tạo mới hoặc sao chép một kho lưu trữ hiện có.

git init

git clone [url]

Thêm & Lưu thay đổi (Add & Commit)

Đưa các thay đổi vào khu vực chờ và lưu chúng vào lịch sử.

git add .

git commit -m "Thông điệp commit"

Kiểm tra trạng thái & Lịch sử

Xem những file nào đã thay đổi và lịch sử các lần commit.

git status

git log

Đồng bộ hóa (Push & Pull)

Cập nhật code từ server về máy hoặc đẩy code từ máy lên server.

git pull origin main

git push origin main

Nhánh (Branching)

Làm việc với các nhánh để phát triển tính năng song song.

git branch

git checkout -b [tên-nhánh-mới]
